base class
    contains methods to handle scenarios common to all UI elements
        example:
            handleClick()
            when user clicks mouse, find elements that were clicked

derived class
    contains methods to handle class-specific scenarios
        example:
            onDraw()
            each class represents some UI element which is drawn in some way
    contains function pointers -- function pointees are defined at runtime
        function pointees handle instance-specific scenarios
            example:
                onClick()
                this is useful because each instance can have different onClick behavior
                otherwise, we would have to create a new subclass for every onClick 
                behavior

another slightly odd thing is that the polymorphism is "one layer down"
    BaseElt has various methods which are not virtual -- handleClick(), etc
        these methods do some common stuff and *then* call virtual methods in derived class

derived classes also contain different data
